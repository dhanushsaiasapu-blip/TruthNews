Truth Privacy Policy

Effective date: September 14, 2026

Truth is a source-first news reading application. Truth does not require an account, registration, password, or authentication.

Information stored on the device

Truth stores app preferences and locally saved bookmarks on the user's device. These local records are used to provide bookmarks and app preferences and are not account records.

If a user writes feedback in the app, the feedback text may be retained locally. When the user chooses to send feedback, the device's email application is opened and the user controls whether the message is sent.

News and network requests

Truth requests news from its configured HTTPS backend. The backend may retrieve articles from news providers and perform processing such as summarization or classification on retrieved source material. Truth does not place provider API credentials in the mobile application.

Third-party services

The application uses Flutter and third-party software libraries for networking, image loading, local preferences, routing, sharing, and other functionality. The publisher should review the privacy behavior and Data Safety requirements of the exact versions shipped in production.

Data security

Network communication between the app and its production backend should use HTTPS. Local bookmark data is stored using the device's application storage.

Data deletion

Truth does not create user accounts, so there is no Truth account to delete. Users can remove locally stored bookmarks and app data through the app/device. Server-side processing is governed by the backend operator's published practices.

Contact

For privacy questions, contact the publisher using the current support/privacy contact shown on the Google Play listing.
