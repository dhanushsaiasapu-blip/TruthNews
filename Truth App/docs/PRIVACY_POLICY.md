# Truth Privacy Policy

**Effective date:** September 14, 2026

Truth is a source-first news reading application. Truth does not require an account, registration, password, or authentication.

## Information stored on the device

Truth stores app preferences and locally saved bookmarks on the user's device. These local records are used to provide bookmarks and app preferences and are not account records.

If a user writes feedback in the app, the feedback text may be retained locally. When the user chooses to send feedback, the device's email application is opened and the user controls whether the message is sent.

## News and network requests

Truth requests news from the application's configured HTTPS backend. The backend may retrieve articles from news providers and may perform processing such as summarization or classification on retrieved source material. Truth does not place provider API credentials in the mobile application.

The backend operator is responsible for the privacy practices of the deployed backend and its upstream providers. The published Google Play Data Safety declaration must describe the actual deployed backend and third-party services.

## Third-party services

The application uses Flutter and third-party software libraries to provide networking, image loading, local preferences, routing, sharing, and other app functionality. The publisher is responsible for reviewing the privacy behavior and Data Safety requirements of the exact versions shipped in production.

## Children's privacy

Truth is not designed to collect personal information from children. The publisher should select the target-audience settings in Google Play accurately.

## Data security

Network communication between the app and its production backend should use HTTPS. Local bookmark data is stored using the device's application storage.

## Data deletion

Because Truth does not create user accounts, there is no Truth account to delete. Users can remove locally stored bookmarks and app data through the app/device. Any server-side data handling performed by the production backend is governed by the backend operator's published privacy practices.

## Contact

For privacy questions, use the publisher's current support/privacy contact address published with the Google Play listing.
